# Diyet Programı Hazırlayıcı

Diyetisyenlerin danışana özel altı öğünlü diyet programlarını aynı tasarımı koruyarak PDF ve Word biçiminde oluşturmasını sağlayan çevrimdışı macOS uygulaması.

## İndirme ve çalıştırma

1. **Releases** bölümündeki son sürümden Mac'inize uygun `.dmg` dosyasını indirin:
   - `macOS-Apple-Silicon.dmg`: M1, M2, M3, M4 veya sonraki modeller
   - `macOS-Intel.dmg`: Intel Core i5/i7/i9 işlemcili Mac'ler
2. DMG dosyasını açın.
3. **Diyet Programı Hazırlayıcı** uygulamasını **Applications** klasörüne sürükleyin.
4. İlk çalıştırmada macOS uyarı gösterirse uygulamaya sağ tıklayıp **Aç** seçeneğini kullanın.

Python veya ek bir program kurulması gerekmez. Uygulama internete veri göndermez; belgeler kullanıcının bilgisayarında oluşturulur.

## Desteklenen Mac'ler

- Apple Silicon işlemcili Mac'ler
- Intel işlemcili Mac'ler
